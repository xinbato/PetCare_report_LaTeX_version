\section{Kho lưu trữ mã nguồn (Repository)}
Toàn bộ mã nguồn ứng dụng di động PetCareApp được quản lý phiên bản trên nền tảng GitHub:
\begin{center}
    \textbf{GitHub Repository:} \url{https://github.com/xinbato/PetCareApp}
\end{center}

\section{Yêu cầu môi trường cài đặt}
\begin{itemize}
    \item \textbf{Hệ điều hành Android:} Android 7.0 (API level 24) trở lên.
    \item \textbf{Môi trường lập trình (IDE):} Android Studio Iguana / Jellyfish trở lên.
    \item \textbf{Java Development Kit (JDK):} OpenJDK 17.
    \item \textbf{Gradle Build Tool:} Gradle 8.x trở lên với Android Gradle Plugin 8.3+.
\end{itemize}
